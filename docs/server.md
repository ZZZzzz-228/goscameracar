Веб-PHP этого аккаунта отказывает в чтении файлов вне папки сайта, хотя SSH/PHP CLI
читает их. Поэтому рабочие bootstrap.php и config.php находятся в указанном
каталоге внутри сайта. Прямые HTTP-запросы к обоим PHP-файлам возвращают 403:
действуют `.htaccess` и правило в корневом `.htaccess`. Дополнительно сами PHP-файлы
запрещают прямое выполнение; config.php загружается только после установки
внутреннего флага bootstrap. Пароли остаются только на сервере.

Особенность Timeweb: nginx может отдавать статические файлы, обходя Apache
`.htaccess`. **Не размещать в runtime-каталоге секреты в JSON, TXT, ENV, SQL,
резервные копии или архивы.** Рабочие конфигурация и логика — только PHP-файлы.
Резервные копии сохраняются за пределами папки сайта.

Приложение и админка используют отдельные пароли, отличающиеся от пароля хостинга.
Локальные учётные данные: `.local/access.txt` и `.local/access.json`. Каталог
исключён из Git, его права Windows ограничены текущим пользователем.

## API

Все запросы идут через HTTPS. Кроме health и OPTIONS, требуется POST с JSON.

| Запрос | Тело | Результат |
| --- | --- | --- |
| `api.php?action=login` | `username`, `password` | `token`, `expires_at` |
| `api.php?action=check` | `plate` | `plate`, `decision`: `allowed` или `not_found` |
| `api.php?action=logout` | `{}` | `status`: `ok` |
| `api.php?action=health` (GET) | — | `status`: `ok` при доступной БД |

Для check/logout нужен заголовок `Authorization: Bearer <token>`.
В базе хранится SHA-256 токена, а не его открытое значение. Срок — 8 часов.
`401` означает повторный вход, `422` — некорректные данные, `429` — ограничение
запросов, `503` — временную недоступность. Ни одна ошибка не равнозначна `not_found`.

Лимиты: до 10 попыток входа на пару IP/логин и 100 на IP за 15 минут;
успешный вход сбрасывает счётчик пары IP/логин. До 180 проверок в минуту
на пользователя. Старые токены и счётчики периодически удаляются при входе.

Веб-просмотр разрешён с самого сайта и с `http://localhost:5180`,
`http://127.0.0.1:5180`. Другие Origins нужно явно добавить в закрытый config.php.

## Обновления

Публичные исходники копируются в папку сайта, `bootstrap.php` — в рабочую папку
`.ht-goscameracar` внутри сайта.
Перед заменой файлов проверяйте их через `php -l` и сохраняйте предыдущие версии.
Не копируйте `.local` в публичную папку. Не перезаписывайте `config.php` при
обновлении кода. `install.php` предназначен только для первой установки и откажется
работать, если конфигурация уже существует. Вторым аргументом установщика после
пути к provision.json передаётся абсолютный путь runtime-каталога. Установщик
и schema.sql остаются вне сайта; в runtime копируются только PHP-файлы и `.htaccess`.

`server/prepare_install.py` генерирует начальные учётные данные для новой установки;
на настроенном проекте повторно запускать его не нужно.

## Поля и поведение

`users`: отдельные роли admin/guard и признак активности.
`vehicle_passes`: уникальный нормализованный номер, комментарий, время создания.
`api_tokens`: хеши токенов и срок действия.
`request_limits`: счётчики запросов.

Номер хранится латинскими символами одинаково на Dart и PHP, отображается кириллицей.
Формат: буква, три цифры, две буквы; регион из двух или трёх цифр необязателен. Проверка через API не учитывает регион (поиск по первым шести символам). Другие страны,
мотоциклетные, военные и специальные номера пока не поддерживаются.

Вкладка «Пользователи» создаёт и редактирует логин, пароль, роль admin/guard и активность.
Секретные пароли не выводятся обратно в формы. Изменения отзывают API-токены;
пароль меняет контрольный хеш сессии админки. Защищены последний администратор и
собственное отключение. Логика находится в защищённом manage_users.php.
