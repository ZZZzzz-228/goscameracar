# Камера

Камера ищет номер по всему кадру. Рамки и кнопки «Следующая машина» нет.
После двух независимых совпадающих считываний выполняется HTTPS-запрос.
Во время запроса обработка приостановлена; после ответа автоматически продолжается.
Результат и номер показываются компактной плашкой вверху камеры до 4 секунд.
При обнаружении другого номера прежняя плашка убирается.

Одна стоящая машина проверяется один раз. Другая машина допускается сразу после
двух считываний. Повтор того же номера возможен, если он отсутствовал в наблюдаемых
кадрах не менее 1,5 секунды. Кратковременный нечёткий кадр не создаёт новый проезд.
При ручном вводе и открытии истории распознавание приостановлено.

Регион необязателен: основная часть номера достаточна и для OCR, и для базы.
Если регион виден, он сохраняется в истории. Отдельный регион объединяется с номером
по направлению текста, поэтому допустимы наклоны и повороты. Буквы O/цифры 0 и другие
неоднозначные замены не угадываются.

## Скорость и ориентация

- Искусственной паузы 140 мс между распознаваниями больше нет. Обрабатывается
  один кадр, затем берётся следующий доступный; очередь старых кадров не накапливается.
- Для читаемого номера следующий кадр сразу обрезается вокруг цели. Зум камеры
  не задерживает подтверждение уже читаемого номера.
- ML Kit прогревается при запуске приложения и остаётся готов между открытиями камеры.
- При неудаче дополнительно проверяются направления 0/90/180/270, по одному на новом
  кадре. Успешное направление сохраняется для подтверждения.
- Android использует NV21 и нативный поворот; для iOS BGRA поворачивается в отдельном
  изоляте. Координаты переводятся обратно для фокусировки и предпросмотра.
- Смена ориентации телефона сбрасывает старую геометрию; запоздавшие результаты
  предыдущей ориентации игнорируются. Предпросмотр учитывает ориентацию камеры,
  даже когда ориентация интерфейса отличается.
- Полный кадр повторяется примерно через 500 мс; одна попытка подтверждения имеет
  приоритет. Потеря номера в обрезке возвращает полный поиск на следующем кадре.
- При неполном номере доступен аппаратный зум шагами до 1,5×, всего до 3×; у края
  кадра он ограничен, чтобы не обрезать цель. Изображение дополнительно центрируется.
- После изменения аппаратного зума выдерживается 140 мс; такие кадры не используются.

Плагин camera_android ограничивает поток профилем 720p; на Infinix поток 1280×720.
Фактическая скорость зависит от освещения, резкости, телефона и ответа сервера.
Очень маленький или закрытый номер может потребовать подойти ближе.

## Проверки

Нативный ML Kit на Infinix распознал искусственный номер при 18 углах от 0 до 330°,
включая 90°, 180° и 270°. Это проверка вращения изображения, а не всех возможных
перспектив и условий на улице. Проверены аппаратный зум, фокус и NV21-обрезка.

Модульные тесты проверяют геометрию, BGRA, отдельный регион, номер без региона,
непрерывные проезды и подавление повторов. Проверки интерфейса охватывают автоматический
переход, историю, ошибки связи и поздние ответы. Нужен повторный прогон финальной
сборки на физическом телефоне; iOS требует Mac/Xcode.
