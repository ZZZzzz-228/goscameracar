# Если при входе нет ответа сервера

Сначала открыть `https://cv339126.tw1.ru/goscameracar/api.php?action=health`.
Исправный ответ — HTTP 200, `{"status":"ok"}`. Ошибка 503 также в браузере
означает серверную проблему; увеличение таймаута телефона её не исправит.

В этой установке устранён отказ веб-PHP читать конфигурацию вне папки сайта.
Текущие пути и меры защиты описаны в `server.md`.

## DNS Android-эмулятора

Эмулятор может сохранить неработающий DNS при смене сети или использовании VPN.
В таком случае IP сервера доступен, но домен не находится. Проверка:

```powershell
adb -s emulator-5554 shell ping -c 1 -W 3 cv339126.tw1.ru
```

Для холодного запуска AVD с явным DNS сначала завершите его через Device Manager.
Данные AVD удалять не нужно. Затем:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\emulator\emulator.exe" -avd Pixel_10_Pro -dns-server 1.1.1.1,8.8.8.8 -no-snapshot-load
```

Это меняет DNS только для данного запуска эмулятора. Системный DNS Windows,
настройки VPN и адрес API приложения не меняются. На настоящем телефоне
используется его собственное подключение к интернету.

## Проверка с настоящего Android-устройства

```powershell
flutter devices
flutter test integration_test/api_connection_test.dart -d DEVICE_ID
flutter run -d DEVICE_ID
```

Тест проверяет HTTPS health и ответ на заведомо неверные данные входа. Реальный
пароль в тестовый APK не вшивается. Последняя команда запускает обычное приложение
вместо интеграционного теста.
