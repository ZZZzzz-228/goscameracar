# Автопропуск

Flutter/Dart для Android и iPhone; MySQL и HTTPS API на Timeweb.

## Текущая версия

- Минимальный вход: щит, логин, пароль, кнопка «Войти».
- Главный экран: «Машина», «История», выход.
- Непрерывное распознавание: следующая машина проверяется автоматически.
- Компактный результат с номером сверху камеры, исчезает через 4 секунды.
- Два последовательных считывания; одна стоящая машина не создаёт повторов.
  Повторный проезд того же номера допускается после отсутствия в кадре 1,5 секунды.
- Номер можно вводить с регионом или без. База сравнивает первые шесть символов:
  А123ВС, А123ВС77 и А123ВС199 имеют одинаковый статус допуска.
- История всех выполненных проверок, включая ошибки связи, сохраняется на устройстве
  отдельно для каждого логина. Видны номер, время и результат; фотографии не сохраняются.
- Поиск по всему кадру, автозум, автофокус, фонарик, повороты и наклон камеры.
- Админка: пропуска и пользователи; роли «Охрана»/«Администратор», логин, пароль,
  активность. Смена пользователя отзывает его API-токены; смена пароля завершает
  прежние сессии админки. Последнего администратора отключить нельзя.
- Иконка приложения — щит, исходник в assets/app_icon.png.

Заданные владельцем пароли хранятся в локальном .local/access.txt, не в исходниках APK.
Учётные записи редактируются на вкладке «Пользователи».

Сессия приложения действует до 8 часов, токен находится в памяти. После полного
закрытия приложения требуется войти снова. История сохраняется после перезапуска;
удаление данных приложения удалит локальную историю.

## Запуск

Откройте C:\progi\goscameracar целиком в Android Studio.
Flutter SDK: C:\Users\kucer\develop\flutter.
JDK 21 закреплён в android/gradle.properties (путь нужно изменить при переносе проекта).

```powershell
flutter pub get
flutter run
flutter build apk --release
```

Готовый Android APK: build/app/outputs/flutter-apk/app-release.apk.
Release-сборка оптимизирована; пока подписана локальным отладочным ключом для
установки и обновления на тестовых устройствах. Перед публикацией нужен отдельный ключ.
Для iPhone требуется Mac/Xcode, iOS 15.5+. На Windows iOS-сборка не выполнялась.

Браузерный просмотр использует ручной ввод:

```powershell
flutter run -d chrome --web-port=5180
```

Демо включается явно через --dart-define=USE_DEMO=true и не подменяет сервер при ошибках.

## Проверки

```powershell
flutter analyze
flutter test
flutter build web
flutter build apk --release
python server/verify_live.py
python server/verify_users.py
flutter test integration_test/recognition_test.dart -d <device-id>
flutter test integration_test/orientation_test.dart -d <device-id>
```

Серверные тесты создают только собственные временные записи и удаляют их.
Нативные проверки изображения выполнялись на Infinix X6831; финальная версия
не установлена на телефон, поскольку он сейчас не подключён.

Описание камеры: docs/camera.md. Сервер: docs/server.md. SSH: docs/timeweb-ssh.md.
